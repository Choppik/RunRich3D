Это шаблон ранера. Здесь реализован генератор уровня, что позволяет играть сколько угодно.
Не добавлены разные мелочи вроде звуков, анимаций, эффектов, декора, нормального UI, дополнительных окон вроде паузы или настроек.
Большая часть логики для ранера реализована. Есть сохранение прогресса, рекорды, валюта, смена меша в зависимости от текущего счета.
Дополнительно: ресурсы сторонние, архитектура MVP, использовались R3 и Addresables, использовался собственный DI контейнер.
